# The probe regression list, read by scripts/Regress.java. One probe per line:
#   <Probe> [solo] [cp=<RAMFS classpath>] [gate=<text the metal output must contain>]
# A probe passes when its metal output equals test/regress/expected/<Probe>.out (the HOST JVM's output),
# or, with gate=, when the output contains that text (DigestProbe/MacProbe differ from the host by design).
# solo = never batched: its subject is first initialization, ordering, timing, global state or the stack itself,
# so running after other probes in the same VM could MASK a failure. "OPEN VM BUG in a batch" marks a probe
# that passes alone but gives a WRONG answer after other probes ran: a real bug, kept solo until it is fixed
# (then the mark comes off). This list is that worklist. Adding a probe: generate its host output
# with javac + java on the seed JDK, check it equals a metal run, commit it as expected/<Probe>.out.
#
# Host recipes that are not plain `java -cp <classes> <Probe>`: GvrProbe/ClassResourceProbe add
# ramfs/lib/junit.jar to -cp; EngineMessageProbe adds out; ReaderProbe takes ramfs/data/sample.txt and
# ReflectLookupProbe ramfs/lib/app.jar as args[0]; LocaleProbe runs with
# -Duser.language=en -Duser.country= -Duser.variant= -Duser.script=. ExcMessageRaceProbe runs with
# -XX:-OmitStackTraceInFastThrow (else HotSpot drops the message of a hot implicit exception).
#
# Compiled into the image (Makefile JDKTESTS) but NOT listed, and why (2026-10-23):
#   METAL-ONLY BY DESIGN, no host control -- ArchiveProbe, BoxCacheProbe (print addresses and image/heap),
#   ResourceProbe, ServiceLoaderProbe (no URL support, denied providers), UsageProbe (os.name, terminal
#   width), SecureRandomProbe, LazyModsProbe (use magic/ or demo/).
#   OTHER -- FirstCallRaceStress (right answer, but QEMU prints LOADER LOCK watchdog lines), EmptySentinelProbe
#   (Set.of order is randomized per host run), JUnitApiProbe (fails an assertion on purpose), PicoDirect and
#   TreeProbe (live in JUnit's packages), MetalJUnit, SampleTest, ProbeBatch (harness pieces).
